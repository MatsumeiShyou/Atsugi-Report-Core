# 厚木事業所_入荷日報 出力要件定義書 (REPORT_SPEC.md)

本ドキュメントは、厚木事業所の入荷日報において、事務員が手作業で作成していたスプレッドシートフォーマットを完全再現するための絶対的な仕様（SSOT）を定義する。
単純なgroupby等による推測集計は禁止され、以下のレイアウトおよびデータマッピング規則に厳格に従うこと。

## 1. 出力先シート1: 「8-5計」（月次推移・マクロ）
**目的**: 13ヶ月の長期的な入荷量推移と、前年同月比較を俯瞰するマクロレポート。

**レイアウト仕様**:
- 縦軸 (346行):
  - 行1〜169: 5大品目 × 収集経路（自社回収・他社回収・持込み）の階層構造。
  - 行172〜184: 横持ち品の階層。
  - 行200〜346: 出荷データの階層。
- 横軸 (16列):
  - A列: 階層見出し（大分類）と、具体的な仕入先名（明細）が同居するインデント構造。
  - B列: 品名詳細（※「⑤その他」に該当するレコードの場合のみ、具体的な元の品名を出力。それ以外は空白）。
  - C〜O列: 過去13ヶ月分の各月の実績値（重量[kg]）。換算なし。
  - P列: 前年同月差（O列(当月) - C列(前年同月) の差分）。

## 2. 出力先シート2: 「8-5」（当月日次詳細・ミクロ）
**目的**: 当月の1日〜末日までの日別入荷明細と、顧客ごとのサマリーを確認するミクロレポート。

**レイアウト仕様**:
- 縦横サイズ: 875行 × 41列
- データ配置:
  - F列〜AJ列: 1日〜31日までの日別実績（重量[kg]）。
  - AK列: 当月の月間合計。
  - AM列〜AO列: 客先サマリー（月間の顧客別集計など）。

## 3. 全体共通の変換（Transformation）規則
1. **実重量の算出**: 実重量 = 正味重量 + 調整重量。マイナス値の調整重量はそのまま相殺して合算する。
2. **横持品の判定**: 仕入先名に拠点キーワードが含まれる場合は「横持品」として分類し、通常のルート分類（自社/他社/持込）から除外する。
3. **5大品目マッピング**: 規定のロジックに基づき、品名を「①段ボール」「②新聞」「③雑誌」「④プラ類」「⑤その他」へ分類する。
4. **主要顧客マッピング**: 固定リストに存在しない仕入先名はすべて「そのた」に置換して集計する。
5. **プレス品判定**: 品名に「プレス」が含まれる場合は「プレス品」とし、経路分類の対象外とする。
