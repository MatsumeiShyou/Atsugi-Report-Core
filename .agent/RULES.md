# 品質定義ファイル (Quality Rules)

## 1. バッチ処理の基本原則
- 本システムは完全自動化されたバッチ処理として設計されること。
- 副作用のある処理（スプレッドシートへの書き込みなど）は必ずエラーハンドリングを実装し、途中で停止した場合も再実行可能（冪等性）な設計とすること。

## 2. 決定論的検証ゲート
コードの変更をマージ・デプロイする前に、以下の決定論的検証ゲートをすべてパス（PASS）しなければならない。

- **型検査 (mypy)**
  - コマンド: `mypy src/`
  - 警告およびエラーがゼロであること。
- **ユニットテスト (pytest)**
  - コマンド: `pytest tests/`
  - 全てのテストが成功すること。カバレッジの低下を防ぐこと。
